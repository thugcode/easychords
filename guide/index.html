기타 가이드

노래하며 기타 치는 사람을 위한 가이드

카포, 바레 코드, 키 바꾸기처럼 실제로 곡을 칠 때 막히는 부분을 정리했어요.

  • 카포 완벽 가이드: 원리부터 위치별 키 계산표까지기타 카포가 무엇이고 왜 쓰는지, 카포 위치에 따라 실제 키가 어떻게 바뀌는지 표로 정리했어요. 초보자가 자주 하는 실수와 카포 끼우는 요령까지.
  • 바레 코드가 안 잡힐 때: 원인별 연습법과 피해 가는 방법F 코드와 Bm 같은 바레 코드가 어려운 이유와 단계별 연습법, 그리고 당장 곡을 쳐야 할 때 바레 코드를 피해 가는 세 가지 방법을 정리했어요.
  • 여자 노래를 남자가, 남자 노래를 여자가 부를 때 키 맞추는 법남녀 음역 차이와 옥타브 개념, 노래방 키 조절과 기타 키의 관계, 내 목소리에 맞는 키를 찾는 실전 방법을 정리했어요.
  • 코드 이름 읽는 법: m, 7, maj7, sus4, 슬래시 코드까지Am7, Cmaj7, Dsus4, G/B처럼 복잡해 보이는 코드 이름을 어떻게 읽고, 어떤 소리가 나며, 초보자는 어떻게 단순하게 바꿔 칠 수 있는지 정리했어요.
  • 키 바꾸기(트랜스포즈) 원리와 기타 치기 쉬운 키코드를 반음 단위로 옮기는 원리, 키마다 자주 나오는 코드 표, 기타로 치기 쉬운 키와 어려운 키를 정리했어요.
  • 기타 초보가 먼저 익힐 개방현 코드 8개와 연습 순서C, G, D, A, E, Am, Em, Dm 여덟 개 개방현 코드의 운지와 연습 순서, 코드 전환을 빨리 하는 요령을 정리했어요.
  • 스트로크 리듬 패턴 4가지: 칼립소·8비트 고고·16비트 슬로우 고고·셔플악보에 박자가 없어도 곡 분위기에 맞춰 칠 수 있는 기본 스트로크 패턴 4가지와 세는 법, 강세 넣는 법, 연습 순서를 정리했어요.
  • 분수 코드(슬래시 코드) 완전 정리: C/E, G/B, D/F♯ 치는 법슬래시 뒤의 음이 무엇을 뜻하는지, 왜 쓰는지, 자주 나오는 분수 코드의 운지와 베이스 라인 만드는 법을 정리했어요.
  • 코드 구성음 쉽게 이해하기: 음정 공식으로 어떤 코드든 읽기Bmadd9, C♯m7♭5처럼 처음 보는 코드도 음정 공식만 알면 구성음을 직접 구할 수 있어요. 반음 세는 법부터 코드별 공식표, 기타에서 음을 빼는 요령까지.
  • 쉬운코드 사용법: 악보 붙여 넣고 카포 추천 받기쉬운코드에 코드 악보를 붙여 넣고, 키를 조절하고, 카포 추천과 운지법을 확인하는 방법을 순서대로 안내해요.
