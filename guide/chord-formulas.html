기타 가이드

코드 구성음 쉽게 이해하기: 음정 공식으로 어떤 코드든 읽기

코드 이름은 사실 '근음에서 몇 칸 떨어진 음을 쌓으라'는 공식이에요. 공식표 한 장이면 모르는 코드가 나와도 겁낼 필요가 없어요.

1단계: 반음 세기

음악의 12음은 반음 간격으로 돌고 돌아요: C C♯ D D♯ E F F♯ G G♯ A A♯ B 다음은 다시 C예요. E와 F, B와 C 사이에는 검은 건반이 없어서 바로 반음이에요. 기타에서는 한 프렛이 반음이라서 지판 위에서 세면 더 쉬워요.

2단계: 음정 이름 익히기

근음에서 몇 반음 떨어졌는지에 이름이 붙어 있어요. 코드 공식은 이 이름들로 쓰여요.

9·11·13은 한 옥타브 위의 2·4·6과 같은 음이에요. 이름을 다르게 부르는 건 '7음 위에 더 쌓았다'는 뜻을 담기 위해서예요. add9는 7음 없이 9음만 더한 코드예요.

직접 해 보기: Bmadd9

  1. 근음은 B예요.
  2. 공식 1 ♭3 5 9를 반음으로 바꾸면 0, 3, 7, 14(=2)예요.
  3. B에서 3반음 위는 D, 7반음 위는 F♯, 2반음 위는 C♯이에요.
  4. 그래서 Bmadd9 = B D F♯ C♯이에요.

음 이름은 알파벳을 건너뛰지 않게 붙이는 게 원칙이에요. C♯m7♭5의 ♭5는 C♯에서 6반음 위라서 소리는 A♭과 같지만, C♯-E-G-B로 알파벳이 하나씩 건너가야 하니 G라고 써요. 이름이 정확하면 코드 안에서 그 음이 맡은 역할(3음인지 5음인지)이 바로 보여요.

기타에서는 음을 빼도 돼요

기타는 줄이 여섯 개이고 손가락은 네 개라서, 구성음이 많은 코드는 다 누르기 어려워요. 그래서 빼도 되는 음이 정해져 있어요.

  • 5음: 가장 먼저 빼요. 빠져도 코드 성격이 거의 그대로예요.
  • 9음: 11·13 코드에서는 빼도 돼요.
  • 절대 빼면 안 되는 음: 3음(메이저/마이너를 결정), 7음(7 코드의 성격), 코드 이름에 직접 적힌 음(add9의 9, aug의 ♯5 등)이에요.

반대로 같은 음을 여러 줄에서 겹쳐 쳐도 괜찮아요. C 코드(x 3 2 0 1 0)도 C와 E를 두 번씩 쳐요.
