기타 가이드

기타 초보가 먼저 익힐 개방현 코드 8개와 연습 순서

이 여덟 개만 익혀도 C·G·D 키의 노래 대부분을 칠 수 있어요. 카포까지 쓰면 거의 모든 키를 커버할 수 있어요.

운지 표기 읽는 법

아래 표기는 6번 줄(가장 굵은 줄)부터 1번 줄 순서예요. 숫자는 누르는 프렛, 0은 누르지 않고 치는 개방현, x는 치지 않는 줄이에요.

먼저 익힐 8개

코드운지(6→1번 줄)포인트
Em0 2 2 0 0 0손가락 두 개로 끝나는 가장 쉬운 코드
Amx 0 2 2 1 06번 줄은 치지 않아요
E0 2 2 1 0 0Am 모양을 한 줄씩 위로 옮긴 모양
Cx 3 2 0 1 0약지가 5번 줄 3프렛, 1번 줄이 막히지 않게
G3 2 0 0 0 36줄 모두 쳐요
Dx x 0 2 3 24개 줄만 쳐요
Ax 0 2 2 2 0세 손가락을 2프렛에 나란히
Dmx x 0 2 3 1D에서 1번 줄만 1프렛으로

연습 순서

  1. Em → Am → E: 모양이 비슷해서 서로 옮기기 쉬워요.
  2. C → Am: 검지와 중지는 그대로 두고 약지만 옮기면 돼요.
  3. G → C → D: 가장 많이 쓰는 진행이에요. 이 세 개가 자연스러워지면 수많은 곡을 칠 수 있어요.
  4. D → A → Dm: 손가락 위치가 가까운 코드끼리 묶어 연습해요.

코드 전환을 빨리 하는 요령

  • 공통 손가락 남기기: C → Am처럼 같은 자리에 있는 손가락은 떼지 말고 미끄러지듯 옮기세요.
  • 손가락 동시에 내리기: 한 손가락씩 놓지 말고, 모양을 공중에서 만든 뒤 한 번에 내려놓는 연습을 하세요.
  • 박자 먼저 지키기: 전환이 늦어도 오른손 박자는 멈추지 마세요. 처음엔 소리가 조금 지저분해도 리듬이 끊기지 않는 게 더 중요해요.
