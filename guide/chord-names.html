기타 가이드

코드 이름 읽는 법: m, 7, maj7, sus4, 슬래시 코드까지

코드 이름은 규칙만 알면 어렵지 않아요. 맨 앞 글자, 그 뒤에 붙는 기호, 슬래시 뒤 음 세 부분으로 나눠 읽으면 돼요.

1. 맨 앞 글자: 근음

코드 이름의 첫 글자(C, D, E, F, G, A, B)는 코드의 바탕이 되는 음, 근음이에요. 뒤에 붙은 ♯(샵)은 반음 올림, ♭(플랫)은 반음 내림이에요. C♯과 D♭처럼 이름은 다르지만 같은 소리인 경우가 있는데, 이걸 이명동음이라고 해요. 기타로는 똑같이 잡으면 돼요.

2. 뒤에 붙는 기호: 코드의 성격

표기읽는 법느낌초보자 대체
C메이저밝고 안정적—
Cm마이너어둡고 슬픈—
C7세븐스(도미넌트)다음 코드로 넘어가고 싶은 긴장감C
Cmaj7메이저 세븐스부드럽고 몽환적C
Cm7마이너 세븐스차분하고 세련된Cm
Csus4서스포살짝 붕 뜬, 해결을 기다리는C
Cadd9애드나인맑고 반짝이는C
Cdim디미니쉬불안하고 긴장된(곡마다 다름)

"초보자 대체" 열은 소리 성격이 조금 달라지지만 곡 흐름은 크게 해치지 않는 기본 코드예요. 어려운 코드를 만나면 일단 대체 코드로 치고, 익숙해지면 원래 코드로 바꿔 보세요.

3. 슬래시 뒤의 음: 베이스

G/B는 "G 코드인데 가장 낮은 음은 B로"라는 뜻이에요. 베이스 음이 계단처럼 이어지게 할 때 많이 써요(예: C → G/B → Am). 초보자는 슬래시 앞 코드만 잡아도 충분해요. G/B 대신 G를 치면 돼요.

자주 헷갈리는 표기

  • CM7 = Cmaj7 = CΔ7: 모두 메이저 세븐스예요. 대문자 M은 메이저, 소문자 m은 마이너예요.
  • Cm7♭5 = Cø: 하프 디미니쉬. 재즈·발라드에서 가끔 나와요.
  • C2 / Csus2: 3음 대신 2음을 쓴 코드로, 맑은 느낌이에요.
