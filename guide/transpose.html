기타 가이드

키 바꾸기(트랜스포즈) 원리와 기타 치기 쉬운 키

키를 바꾼다는 건 모든 코드를 같은 간격만큼 옮기는 거예요. 원리를 알면 손으로도 계산할 수 있어요.

반음 12개의 원

음이름은 반음 간격으로 12개가 돌고 돌아요.

C → C♯ → D → D♯ → E → F → F♯ → G → G♯ → A → A♯ → B → (다시 C)

E와 F, B와 C 사이에는 ♯이 없다는 점만 기억하면 돼요. 키를 2만큼 올리려면 모든 코드의 근음을 이 원에서 오른쪽으로 두 칸씩 옮기면 돼요. 코드 뒤에 붙은 m, 7 같은 기호는 그대로 둬요.

예: G – Em – C – D를 2만큼 올리면 A – F♯m – D – E가 돼요.

키마다 자주 나오는 코드

한 키 안에서는 보통 정해진 일곱 개 코드가 주로 쓰여요. 기타로 많이 치는 키를 정리하면 이래요.

키IiiiiiIVVvi
CCDmEmFGAm
GGAmBmCDEm
DDEmF♯mGABm
AABmC♯mDEF♯m
EEF♯mG♯mABC♯m
FFGmAmB♭CDm

기타로 치기 쉬운 키, 어려운 키

  • 쉬운 키: C, G, D — 주요 코드 대부분이 개방현 코드예요. G 키는 Bm, D 키는 F♯m 하나 정도만 바레예요.
  • 중간: A, E, Am, Em — 개방현 코드가 많지만 C♯m, G♯m 같은 바레가 섞여요.
  • 어려운 키: F, B♭, E♭, A♭ 같은 플랫 키 — 피아노·관악기에는 편하지만 기타에서는 바레 코드가 많아요. 카포로 쉬운 키 모양을 쓰는 게 좋아요.

키를 바꿀 때 꼭 확인할 것

  1. 노래 음역: 기타가 편해도 노래가 불편하면 소용없어요. 먼저 부를 키를 정하고, 그다음 카포로 손 모양을 맞추세요.
  2. 원곡과 같이 칠 건지: 음원에 맞춰 칠 거라면 키는 그대로 두고 카포만 쓰세요.
  3. 같이 연주하는 사람: 다른 악기와 합주한다면 실제 소리 기준의 코드 이름(카포 없이 쓴 코드)으로 소통하세요.
