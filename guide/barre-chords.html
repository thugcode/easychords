바레 코드가 안 잡힐 때: 원인별 연습법과 피해 가는 방법

기타를 시작한 사람 대부분이 F 코드에서 한 번은 멈춰요. 왜 어려운지 알면 연습 방향이 보이고, 당장은 피해 가는 방법도 있어요.

바레 코드란

바레(barre)는 검지 하나로 같은 프렛의 여러 줄을 한꺼번에 누르는 주법이에요. 대표적인 코드가 F(1프렛 바레)와 Bm(2프렛 바레)이에요. 개방현을 쓰지 않으니 같은 모양을 지판 위아래로 옮기기만 하면 다른 코드가 된다는 장점이 있지만, 처음에는 소리가 '틱틱' 끊기기 쉬워요.

소리가 안 나는 세 가지 원인

1. 검지의 힘이 아니라 '각도' 문제

검지 안쪽의 살이 부드러운 부분은 줄을 제대로 누르지 못해요. 검지를 기타 헤드 쪽으로 살짝 굴려서 뼈에 가까운 옆면으로 누르면 같은 힘으로도 소리가 훨씬 잘 나요.

2. 손가락 관절 주름에 줄이 걸림

검지 마디의 접히는 부분에 줄이 걸리면 그 줄만 소리가 죽어요. 검지를 위아래로 몇 밀리미터씩 옮겨 보며 모든 줄이 울리는 위치를 찾으세요.

3. 손으로만 누르려 함

엄지로 넥 뒤를 꽉 쥐는 것보다, 팔 무게로 살짝 당기는 느낌이 더 효과적이에요. 오른팔로 기타 몸통을 몸 쪽으로 받쳐 주면 왼손 힘이 훨씬 덜 들어요.

일주일 연습 순서

  1. 1~2일차: 5프렛 근처에서 검지 바레만 잡고 한 줄씩 쳐 보기. 프렛 간격이 좁아 1프렛보다 쉬워요.
  2. 3~4일차: 같은 위치에서 E형 바레 코드(검지 바레 + 나머지 손가락)를 잡고 떼기를 반복하기.
  3. 5~6일차: 3프렛, 2프렛, 1프렛 순서로 내려오며 같은 연습하기.
  4. 7일차: C → F, Am → F처럼 실제 곡에서 자주 나오는 전환 연습하기.

하루 5~10분이면 충분해요. 손가락이 아프면 쉬는 게 오히려 빨리 늘어요.

당장 쳐야 한다면: 바레 코드를 피해 가는 방법

방법 1. 카포로 키 옮기기

바레 코드가 많은 키를 카포와 쉬운 모양으로 바꾸는 방법이에요. 예를 들어 B♭ 키 곡(B♭, F, Gm, E♭)은 카포 3에 G 모양(G, D, Em, C)으로 치면 바레 코드가 하나도 없어요.

방법 2. 비슷한 소리의 대체 코드 쓰기

  • F 대신 Fmaj7 (xx3210): 1~3번 줄만 누르는 모양이라 바레가 없고, 대부분의 곡에서 자연스럽게 어울려요.
  • Bm 대신 Bm7 (x20202): 개방현을 섞은 모양이라 훨씬 쉬워요.

방법 3. 작은 바레(미니 F)

6줄을 다 누르지 않고 1~4번 줄만 쓰는 F(xx3211)는 검지로 두 줄만 누르면 돼요. 풀 바레로 넘어가기 전 중간 단계로 좋아요.
