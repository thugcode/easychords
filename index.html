씽키는 이럴 때 필요해요

노래방에서는 버튼 하나로 키를 바꾸지만, 기타는 키를 바꾸면 코드가 전부 바뀌어요. 원곡 키가 내 목소리에 맞지 않을 때, 인터넷 악보에 F·Bm 같은 바레 코드가 가득할 때, 처음 보는 코드 이름이 나올 때 씽키가 대신 계산해 드려요.

키 바꾸기

악보를 붙여 넣고 −/+로 반음씩 조절하면 모든 코드가 함께 바뀌어요. 가사, 줄 바꿈, 마디 기호는 그대로 두고, 분수 코드의 베이스 음까지 올바른 이름으로 옮겨요.

카포 추천

같은 높이로 소리 나는 카포 0~7번을 모두 비교해서 바레 코드가 가장 적은 위치를 추천해요. 목록에서 다른 위치를 직접 고를 수도 있어요.

운지와 코드 사전

곡에 나온 코드는 운지 그림으로 모아 보여 줘요. Bmadd9, C♯m7♭5처럼 낯선 코드는 코드 사전에서 구성음, 잡기 쉬운 운지, 하이코드까지 확인할 수 있어요.

리듬 가이드

칼립소, 8비트 고고, 16비트 슬로우 고고, 셔플 패턴을 화살표로 보여 주고, 메트로놈처럼 박자에 맞춰 칸마다 불이 들어와요.

자주 묻는 질문

어느 사이트의 악보를 붙여 넣어야 하나요?

코드가 글자로 적힌 악보라면 어느 사이트든 괜찮아요. 코드가 가사 위 줄에 있는 형식과 [C]처럼 괄호 안에 있는 형식을 모두 읽어요. 악보에 적힌 카포 위치는 자동으로 반영하고, 튜닝·타브 줄은 코드로 읽지 않아요. 사진이나 이미지로 된 악보는 읽지 못해요.

여자 노래를 남자가 부르려면 몇 키를 내려야 하나요?

보통 5키 정도 내리는 데서 시작하지만 목소리마다 달라요. "여 → 남" 버튼으로 출발점을 잡고, ▶ 듣기로 들어 보면서 한 키씩 맞추세요. 기타 코드는 옥타브를 구분하지 않아서 5키 내린 것과 7키 올린 것은 같은 코드예요.

카포를 끼우면 소리가 달라지나요?

음 높이는 같아요. 다만 개방현이 함께 울려서 바레 코드로 칠 때보다 맑고 풍성하게 들려요. 7프렛을 넘으면 소리가 얇아지고 프렛 간격이 좁아져서 추천하지 않아요.

"쉬운 코드로"를 켜면 무엇이 바뀌나요?

Cmaj7 → C, B♭7sus4 → B♭7처럼 소리가 비슷하면서 더 쉬운 모양이 있는 코드를 바꿔 보여 줘요. 원래 코드를 그대로 보고 싶으면 끄면 돼요. 끈 상태에서도 모양이 없는 코드는 운지를 계산해서 보여 줘요.

원곡 키가 다르게 나와요.

원곡 키는 코드 진행을 보고 추정한 값이라 가끔 다를 수 있어요. 키 이름만 다르게 보일 뿐 코드 변환과 카포 추천 결과에는 영향이 없어요.

붙여 넣은 악보가 저장되나요?

서버로는 보내지 않아요. 악보와 가사는 사용 중인 브라우저 안에서만 처리돼요. ‘저장’을 누른 악보만 나중에 다시 볼 수 있게 이 브라우저에 보관되고, ‘저장한 악보’에서 언제든 지울 수 있어요.

무료인가요?

네, 회원가입 없이 모든 기능을 무료로 쓸 수 있어요. 사이트 운영비는 광고로 충당해요.
